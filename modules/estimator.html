Atom Contribution Estimator

class polymon.estimator.atom_contrib.AtomContribEstimator(atom_contrib: ndarray)[source]

Bases: BaseEstimator

Atom contribution estimator. It is used to estimate the label of a polymer based on the atom composition.

Parameters:

atom_contrib (np.ndarray) – The atom contribution coefficients. It is a 1D array of shape (MAX_NUM_ELEMENTS,). The i-th element is the contribution of the i-th element to the label. The i-th element is the number of atoms of the i-th element in the polymer. The MAX_NUM_ELEMENTS is 100.
